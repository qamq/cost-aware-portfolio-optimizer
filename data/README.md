# Data

No proprietary or licensed financial data are distributed with this repository.

The standalone optimizer operates on user-supplied vectors or tables for:

- expected-return or ranking signals;
- covariance estimates;
- previous portfolio weights;
- forecast daily dollar ADV;
- forecast daily return volatility; and
- one-way spread estimates.

The examples use synthetic inputs only. See [`docs/DATA.md`](../docs/DATA.md) for units and schema conventions.
